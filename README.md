# Lab Cybersecurity

Repositório criado para documentar minha evolução prática em Linux, redes, automação e fundamentos de cibersegurança.

## Objetivo

Construir um portfólio técnico com laboratórios reais, comandos executados, scripts desenvolvidos e aprendizados adquiridos durante minha transição para a área de TI, com foco em infraestrutura, Linux e segurança.

## Áreas de estudo

- Linux
- Bash Script
- Processamento de logs
- Redes
- Automação
- Fundamentos de Cybersecurity
