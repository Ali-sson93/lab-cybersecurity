# Lab Cybersecurity

Repositório criado para documentar minha evolução prática em Linux, automação, redes e fundamentos de cibersegurança.

## Sobre este repositório
Este repositório reúne laboratórios práticos, scripts, testes e anotações desenvolvidos durante minha transição para a área de Tecnologia da Informação, com foco em:

- Linux
- Bash Script
- Automação
- Processamento e análise de logs
- Redes e infraestrutura
- Fundamentos de Cybersecurity

O objetivo é construir um portfólio técnico com evidências reais de aprendizado, mostrando não apenas teoria, mas também a prática de comandos, criação de scripts, organização de arquivos, versionamento com Git e resolução de problemas em ambiente Linux.

## Objetivo profissional
Estou em transição para a área de TI, direcionando meus estudos para Linux, infraestrutura, redes e segurança da informação.  
Este repositório funciona como meu laboratório de evolução prática, onde documento o que estudo, testo e desenvolvo ao longo da jornada.
