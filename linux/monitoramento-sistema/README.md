# Monitoramento de Sistema Linux

Projeto desenvolvido durante meus estudos de Linux na Alura.

## Objetivo

Criar um script Bash para monitorar automaticamente o sistema operacional.

## Recursos implementados

- Monitoramento de logs do sistema (syslog e auth.log)
- Filtragem utilizando grep com Expressões Regulares
- Processamento utilizando awk
- Verificação de conectividade com ping
- Verificação de aplicações usando curl
- Monitoramento do uso de disco com df
- Organização do código utilizando funções Bash
- Geração automática de relatórios
- Estrutura preparada para execução automática com cron

## Comandos utilizados

- grep
- awk
- ping
- curl
- df
- mkdir
- bash
- if
- else
- funções Bash
